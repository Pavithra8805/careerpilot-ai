# Web (Next.js) — Quick Guide

This folder holds the Next.js frontend for CareerPilot AI. It is built with React and Tailwind CSS.

Run locally

```bash
cd web
npm install
npm run dev
```

Open: http://localhost:3000

Notes
- The frontend expects the API at `http://localhost:3001` by default.
- If you make environment changes in `api/.env`, restart the backend before testing.
